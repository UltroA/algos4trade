# Алгоритмы: карта ожиданий до реализации

Эта таблица - исходный план исследования, составленный до того, как были написаны какие-либо алгоритмы в `src/algorithms/`. Для каждого семейства алгоритмов указан заранее ожидавшийся ("реалистичный") уровень качества и главная слабость метода - именно на эту таблицу ссылаются докстринги отдельных файлов (`# Realistic level (see docs/Алгоритмы.md): ...`) и `core.base.AlgorithmCategory`/`BaseTradingAlgorithm`, когда сравнивают фактические результаты бенчмарка с исходной гипотезой.

Не путать с фактическими результатами: они - в `results/*.md`/`*.json` (раздел 3 README), посчитаны по реальным данным MOEX и могут отличаться от ожиданий в этой таблице в любую сторону.

|#|Алгоритм|Основное применение в трейдинге|Реалистичный уровень|Главная слабость|
|---|---|---|---|---|
|1|**LightGBM / XGBoost / CatBoost**|Кросс-секционный ранкинг акций по ожидаемой доходности|52–56% направления, IC 0.02–0.05|Переобучение на шумных фичах, нужен purged CV|
|2|**Random Forest**|Базовый бейзлайн, оценка важности признаков|51–54%|Слабее бустинга, сглаживает редкие сигналы|
|3|**Elastic Net / Lasso**|Факторные модели, отбор признаков из сотен альф|Низкая точность, высокая стабильность|Только линейные зависимости|
|4|**Логистическая регрессия**|Прогноз вероятности пробоя/отката, калибровка|51–53%|Требует ручного feature engineering|
|5|**Meta-labeling (Лопес де Прадо)**|Второй слой ML решает «брать ли сделку», выданную первичной моделью|Поднимает winrate на 5–15 п.п.|Не создаёт альфу, только фильтрует|
|6|**HMM (скрытые марковские модели)**|Определение режима рынка: тренд / флэт / стресс|2–4 устойчивых режима|Режимы переопределяются задним числом|
|7|**Фильтр Калмана**|Динамический хедж-коэффициент в парном трейдинге|Высокий winrate (65–75%) при малом профите на сделку|Разрыв коинтеграции = большой убыток|
|8|**Кластеризация (HDBSCAN, correlation clustering)**|Поиск пар и статистических арбитражных корзин|—|Кластеры нестабильны во времени|
|9|**LSTM / GRU**|Последовательности цен, объёмов, потока заявок|51–55%, часто не бьёт бустинг|Долгое обучение, легко переобучается|
|10|**TCN (temporal convolutional)**|То же, что LSTM, но быстрее и стабильнее|Сопоставимо с LSTM|Фиксированное рецептивное поле|
|11|**Transformer (PatchTST, Informer)**|Мультивариантные ряды, длинные горизонты|Хорош на дневках, слаб на тиках|Требует много данных, дорогой|
|12|**N-BEATS / N-HiTS**|Чистое прогнозирование ряда без фич|Сильные бенчмарки на M-соревнованиях|Прогноз цены ≠ прибыльная стратегия|
|13|**CNN по «картинкам» графиков**|Распознавание паттернов на изображениях свечей|52–54%|Чёрный ящик, тяжело отлаживать|
|14|**Autoencoder / VAE**|Сжатие сотен фич в латентные факторы, деноизинг|Улучшает вход другим моделям|Латентные факторы неинтерпретируемы|
|15|**Isolation Forest / One-Class SVM**|Детекция аномалий, риск-выключатель перед крахом|Ловит 60–80% стрессовых дней|Много ложных срабатываний|
|16|**SVM с RBF-ядром**|Классификация направления на малых выборках|51–53%|Плохо масштабируется|
|17|**RL: PPO / SAC / DDPG**|Оптимизация исполнения ордеров и размера позиции|Реально работает в execution|В генерации сигналов почти всегда переобучение на бэктесте|
|18|**Многорукие бандиты / Thompson sampling**|Распределение капитала между работающими стратегиями|Стабильный прирост Шарпа|Не даёт сигналов сам по себе|
|19|**Гауссовы процессы / байесовская оптимизация**|Подбор гиперпараметров + оценка неопределённости прогноза|Позволяет не торговать при низкой уверенности|Плохо масштабируется по данным|
|20|**Генетическое программирование / symbolic regression**|Автоматический поиск формул-альф (как в WorldQuant)|Находит интерпретируемые сигналы|Гигантский риск data mining bias|
